# Auditoria Frontend

## Achados

-   JavaScript ainda é predominante nas páginas;
-   `allowJs` está habilitado;
-   AppShell não existe;
-   Sidebar global não existe;
-   mobile navigation não existe;
-   design system é apenas parcial;
-   estados de interface ainda são inconsistentes;
-   vários componentes são isolados.

## Correção

Consolidar layout, TypeScript, navegação e design system antes da
implementação avançada do produto.
