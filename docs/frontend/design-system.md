# Design System

## Direção visual

Light-only.

Paleta base:

-   Background: `#FFFFFF`
-   Surface: `#F8FAFC`
-   Border: `#E2E8F0`
-   Text: `#0F172A`
-   Secondary: `#64748B`
-   Primary: `#2563EB`
-   Primary Strong: `#1D4ED8`
-   Cyan: `#06B6D4`
-   Success: `#16A34A`
-   Warning: `#D97706`
-   Error: `#DC2626`

## Tipografia

Inter/system-ui.

## Estados

Todo componente interativo deve tratar:

-   default;
-   hover;
-   focus;
-   active;
-   selected;
-   disabled;
-   loading;
-   error.

## Ícones

Usar biblioteca real, preferencialmente `lucide-react`.

Não usar emoji como ícone.
