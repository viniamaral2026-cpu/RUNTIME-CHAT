# Formulários

Todos os formulários críticos devem possuir:

-   schema;
-   validação;
-   mensagens de erro;
-   estado submitting;
-   disabled durante submit;
-   tratamento de resposta;
-   acessibilidade;
-   feedback de sucesso/erro.

A validação no frontend melhora UX, mas não substitui validação no
backend.
