# Mobile

## Requisitos

-   header mobile;
-   botão menu;
-   drawer;
-   overlay;
-   fechamento por Escape;
-   fechamento após navegação;
-   bloqueio adequado do scroll do conteúdo;
-   menus adaptados;
-   editor e terminal por painéis/abas quando necessário.

Mobile não deve ser apenas uma versão comprimida do desktop.
