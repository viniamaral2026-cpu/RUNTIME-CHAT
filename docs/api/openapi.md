# OpenAPI

## Objetivo

O contrato HTTP deve possuir uma especificação OpenAPI versionada.

Ela deve documentar:

-   endpoints;
-   parâmetros;
-   request body;
-   response;
-   authentication;
-   authorization;
-   errors;
-   pagination;
-   rate limits.

A especificação deve ser atualizada junto com mudanças de API.

## Regra

Não gerar documentação baseada em endpoints imaginários. O OpenAPI deve
refletir rotas realmente implementadas.
