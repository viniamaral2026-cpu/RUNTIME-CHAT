# API de Usuários

## Operações

-   obter perfil;
-   atualizar nome;
-   atualizar avatar;
-   alterar preferências;
-   alterar senha;
-   listar sessões;
-   revogar sessão;
-   revogar todas.

## Segurança

O identificador do usuário deve vir da sessão autenticada, não de um
campo arbitrário enviado pelo browser.
