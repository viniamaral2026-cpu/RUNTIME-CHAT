# API de Modelos

O catálogo de modelos deve ser dirigido por backend.

Campos importantes:

-   provider;
-   modelIdentifier;
-   displayName;
-   contextWindow;
-   maxOutputTokens;
-   supportsVision;
-   supportsStreaming;
-   supportsTools;
-   supportsCode;
-   isActive;
-   isDefault.

O frontend não deve inferir capabilities apenas pelo nome do modelo.
