# Environment Variables

## Regra

Este documento lista apenas nomes e finalidade. Valores reais nunca são
documentados.

Categorias esperadas:

-   API base pública;
-   database connection server-side;
-   session configuration;
-   AI provider credentials;
-   storage configuration;
-   deployment configuration.

`NEXT_PUBLIC_*` deve ser tratado como público.

Os nomes reais devem ser reconciliados com o código sem abrir ou
imprimir `.env`.
