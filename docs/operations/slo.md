# SLO / Reliability

Os SLOs finais devem ser definidos com base no ambiente real.

Dimensões:

-   disponibilidade;
-   latência API;
-   latência de primeiro token;
-   duração de streaming;
-   taxa de erro;
-   falha de uploads;
-   falha de terminal;
-   tempo de recuperação.

Nenhum número fictício deve ser apresentado como SLO oficial.
