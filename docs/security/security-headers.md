# Security Headers

Avaliar:

-   Content-Security-Policy;
-   X-Content-Type-Options;
-   Referrer-Policy;
-   Permissions-Policy;
-   Strict-Transport-Security em HTTPS;
-   frame-ancestors / X-Frame-Options conforme CSP;
-   cookies seguros.

A política CSP deve ser testada antes de endurecimento definitivo.
