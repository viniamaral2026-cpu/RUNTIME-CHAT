# Contributing

## Fluxo

``` text
branch
→ implementação
→ testes
→ lint
→ typecheck
→ build
→ documentação
→ commit
→ push
```

## Commits

Usar mensagens que expliquem a mudança.

## Proibição

Não commitar:

-   secrets;
-   `.env`;
-   `.next`;
-   node_modules;
-   logs privados;
-   arquivos temporários.
